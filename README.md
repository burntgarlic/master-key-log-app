# Master Key App

A phone-first PWA for the 26-week Master Key attention curriculum: Timer, Manual, Session Log, and an AI Chat grounded in the manual text.

See [master-key-app-plan.md](./master-key-app-plan.md) for the full architecture and build plan, and [master-key-manual.md](./master-key-manual.md) for the curriculum content.

## Development

```
npm install
npm run dev
```
